# 📈 Stock Growth Analyzer

A Flask-based web application for exploring stock data, calculating growth metrics, and visualizing market trends through an interactive dashboard.

## ✨ Features

- 📊 Stock price and growth analysis
- 📈 Interactive charts and visualizations
- 🗂️ CSV-based data processing
- 🌐 Flask web interface
- 🎨 Responsive dashboard using Bootstrap and Chart.js
- 🧩 Modular backend structure for analysis and visualization

## 🛠️ Tech Stack

**Backend:** Python, Flask  
**Data:** Pandas  
**Frontend:** HTML, CSS, JavaScript, Bootstrap  
**Charts:** Chart.js  
**Data Source:** CSV / market-data workflows

## 🏗️ Application Flow

```text
Stock Data
    ↓
Data Cleaning & Processing
    ↓
Growth / Performance Calculations
    ↓
Flask Backend
    ↓
Interactive Dashboard + Charts
```

## 🚀 Getting Started

```bash
git clone https://github.com/Vileka06/stock-growth-analyzer.git
cd stock-growth-analyzer
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open the local Flask URL shown in your terminal.
